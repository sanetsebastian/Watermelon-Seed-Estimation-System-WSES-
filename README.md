## 📌 Basic Details

### Project Description

WSES is a software-based experimental system designed to estimate the number of seeds inside a watermelon before cutting it open.

The system takes watermelon measurements such as **weight, length, and diameter** and produces an estimated seed count.

Is it useful?

**Absolutely not.**

Did we build it anyway?

**Obviously.** 🍉

---

## 🤡 The Problem (that doesn't exist)

Every year, countless people face a terrifying unanswered question:

> **"How many seeds are inside this watermelon?"**

Normally, the obvious solution is to cut the watermelon open and count them.

But where is the fun in that?

WSES attempts to predict the answer **before the watermelon is cut**, because apparently this was a problem worth solving.

---

## 💡 The Solution (that nobody asked for)

WSES collects measurable watermelon characteristics:

- ⚖️ Weight
- 📏 Length
- ⭕ Diameter

These measurements are processed by the estimation system to produce an estimated number of watermelon seeds.

The result also includes:

- 🌱 Estimated Seed Count
- 🔬 Seed Density
- 👹 Seed Monster Level
- 😂 Uselessness Score

Because simply giving a number wasn't unnecessary enough.
